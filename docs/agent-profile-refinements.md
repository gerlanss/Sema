# Agent Profile Refinements

This note tracks public, non-sensitive refinements for Sema agent profiles.

Profile work must stay aligned with the local CLI contract flow:

- profile behavior is validated through local `.sema` contracts;
- public examples must not require private services or credentials;
- npm distribution must stay aligned with the repository manifests and local
  package smoke tests;
- commercial replicas or resale require written permission from OtimiTare.

# Sema Vocabulary

Use consistent English prose in public docs while preserving technical
identifiers.

## Canonical Concepts

- semantic contract
- drift
- impact map
- governed code
- traceability
- Codex-native
- local runtime
- finalization
- evidence
- local CLI

## Do Not Translate

- commands: `sema validar`, `sema drift`, `sema impacto`
- files: `AGENTS.md`, `SEMA_BOOT.md`, `SEMA_INDEX.json`
- DSL keywords: `task`, `input`, `output`, `rules`, `effects`, `guarantees`
- package names: `@semacode/cli`
- code symbols and environment variable names
